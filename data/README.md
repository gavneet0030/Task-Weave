Dataset: Task resource usage of Google Cluster Usage Trace dataset
Source: https://zenodo.org/records/6979672
DOI: https://doi.org/10.5281/zenodo.6979672
Publisher: Zenodo
Description: Derived CSV files with timestamps and mean CPU usage.
Sampling: 5-minute timestamps.
Intended use: Generate realistic CPU-load patterns for TaskWeave workload experiments.
Important: This is derived machine-usage data, not the complete Google Borg task-submission trace.
